# 곽빈 한 명 — DCC 미술 작업 인계 기준(실제 계약 아님)

대상: 얼굴·머리와 셔츠/소매/목둘레. 하체·신발 추가 장식/투구 모션/다른 선수/경기 시스템 제외. 기준 커밋32438e0. 현재 모델은 미술 미승인이라는 설명을 그대로 전달한다.

인계:
- 편집 가능한 v3 `.blend`, 실제 GLB와 해시,42본 rig-contract,identity.json.
- 컨셉과 실제 WebGL 전후 원본, 동일 조명/카메라 presets.
- 원본 서비스에 import하지 않은 독립 뷰어. 게임/세이브·원본 타격 번들은 인계 아트의 수정 범위 밖.

고정:
- 공통 본 이름/부모/rest pose/단위/축과identityKey를 변경하지 않음.
- 프리뷰를 위해 조명·카메라·렌더 노출을 바꾼 결과는 승인 비교 자료로 사용하지 않음.
- 실사 피부/사진 plane/각도별 다른 얼굴 이미지 사용하지 않음.

납품:
- 작업 history/저해상도 cage/고해상도 sculpt/bake 대상이 구분된 `.blend`.
- 얼굴의 눈·입 loop, 의복 암홀·목둘레·소매 edge flow를 확인할 wireframe.
- UV·재질·텍스처 및 원본 편집 자산, 제작/라이선스 출처 목록.
- 같은42본에 바인딩한 실제 GLB. 불필요한 scene/light/camera/animation 없이 중립 포즈 art pass부터.
- 4방향 중립,3/4 얼굴·목·어깨·상의 확대를 같은 기존 WebGL에서 출력.
- tris/verts/primitives/draw calls/decoded texture 예산. 특정 수치를 지키기 위해 품질을 숨기지 않음.

검수:
1. 컨셉 화풍·선수 개성·같은 인물의 다방향 일관성.
2. 목/암홀/겨드랑이 두께와 안쪽 빈틈, 유니폼 표면 인쇄.
3. UV늘어남·normal/tangent·반전·gamma·재질 슬롯·가림.
4. rest/inverse bind/정규화/max4/미할당 검사. 외형 승인 이후에만 관절 동작.
5. 실제 WebGL 결과와 source DCC의 차이를 공개. 후보가 미달이면 미달로 표시.

외부 제작 비용/계약/권한 승인 전에는 실제 발주하지 않는다. 이 문서는 준비된 요구조건이며 계약·구매를 실행한 기록이 아니다.
