# art/ — 캐릭터 파츠 시트

`mvGuy()` 가 캔버스에 손코딩한 선화(막대인간)로 사람을 그리던 것을
사람이 그린 그림으로 갈아끼우기 위한 작업 폴더다.

## 파일

| 파일 | 뭔가 |
|---|---|
| `sprite2-src.png` | 제미나이가 준 원본 (1200x896, **배경이 구워져 있다**) |
| `sprite.png`      | 배경을 벗긴 것. 실제로 쓰는 것 |
| `parts.json`      | 파츠 12개의 좌표. `slice.js` 가 만든다 |
| `strip.js`        | 체커보드 배경 → 투명으로 벗긴다 |
| `slice.js`        | 파츠 위치를 자동으로 찾아 `parts.json` 을 쓴다 |
| `_check.png`      | 자홍색 배경에 얹어본 확인용. 잔털이 있으면 눈에 보인다 |

## 왜 벗겨야 하나

제미나이에 "투명 배경 PNG" 를 달라고 하면 **투명해 보이는 회색 체커보드를
그려서** 준다. 알파 채널은 전부 255 다. 그대로 넣으면 인물 뒤에 회색 격자가
따라다닌다. `strip.js` 가 테두리에서 번져 들어가며 체커보드 색만 지운다.
포수 마스크 창살처럼 완전히 둘러싸인 구멍도 따로 뚫는다.

## 다시 돌리는 법

새 그림을 받으면:

```
node art/strip.js art/새그림.png art/sprite.png
node art/slice.js art/sprite.png
```

`slice.js` 가 "조각이 12개가 아니다" 라고 하면 파츠 이름이 밀렸다는 뜻이다.
KEYS 배열 순서와 실제 배치가 맞는지 확인해라.

## 파츠를 왜 나눠 받나

통짜 스프라이트로 애니메이션 프레임을 뽑으면 프레임마다 캐릭터가 미묘하게
달라져서 덜덜 떨린다. 부위별로 받아서 **관절 회전은 코드가 만든다.**
그러면 프레임 수가 무제한이고, 포즈를 새로 추가해도 그림이 더 안 필요하다.

## 유니폼 색

시트는 우리 팀(네이비 소매 + 흰 몸통)으로 그려져 있다. 상대 23팀은
네이비 픽셀을 팀 색으로 치환해서 만든다 (오프스크린 캔버스에 한 번 만들고
캐시). 등번호는 그림에 없다 — 선수마다 다르니 캔버스가 직접 그린다.
