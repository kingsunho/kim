# SD 캐릭터 재의뢰 — 코딩 에이전트용 작업 지시서

[요청] "캐릭터도 저렇게 비슷하게 해주고" — 사용자가 게임 영상을 답지로 줬다.
답지 캐릭터는 **머리가 키의 절반인 2등신 SD** 인데 지금 우리 그림은 7등신이다.
카메라·배치·연출을 아무리 맞춰도 캐릭터가 다르면 느낌이 안 난다.

> **왜 코드로 못 하나** — 시도해봤다. 통짜 그림에서 머리 상자만 떠서 2.35배로
> 키우고 목 자리에 얹는 방법이다. 머리는 커지는데 **배트가 머리 뒤로 숨는다**
> (우리 타격 그림은 배트가 머리 위를 가로지른다). 배트만 색으로 떠내서 위에
> 다시 얹어도 **몸 축척이라 큰 머리에 작은 배트가 붕 떠 보인다.**
> 몸까지 눌러 2등신을 만들면 배트가 같이 휘어진다.
> 그림을 새로 그리는 것 말고는 답이 없다. 되돌렸다.

> 사람이 할 일: 아래 `===` 사이만 복사해서 그림 만드는 쪽에 붙여 넣는다.

---

```
===================== 여기부터 복사 =====================

이 저장소(우완좌완 야구 매니저)의 캐릭터 그림을 **2등신 SD** 로 새로 만들어야 한다.

## 1단계 — 먼저 읽어라

  art/_ref_sd_bat.png    답지 — 타자 (이 체형·이 비율로 그린다)
  art/_ref_sd_pit.png    답지 — 투수
  art/_ref_sd_scene.png  답지 — 경기 화면 전체 (크기 비교용)
  art/_ref_figs.png      지금 게임에 들어가 있는 세 장 (7등신 — 이걸 버린다)
  art/packfig.js         결과물 세 장을 시트로 묶는 스크립트
  art/checkbat.js        규격 검사기
  art/strip.js           체커보드 배경을 투명으로 벗기는 도구
  art/README.md          파이프라인 설명

## 2단계 — 무엇을 만드나

세로로 긴 PNG **세 장**. 배경 투명. 각각 인물 한 명.

  art/bat-new.png    우타자 · 타격 준비 자세 · **뒤에서** 본다(등번호 자리가 보인다)
  art/fig-pitw.png   투수 · 와인드업 (다리 들었을 때) · 정면
  art/fig-pit.png    투수 · 릴리스 직후 피니시 · 정면

**시점** — 포수 뒤에서 마운드를 보는 야구 중계 카메라.

## 3단계 — 체형 (여기가 이번 의뢰의 전부다)

답지를 그대로 따라간다:

  · **머리(헬멧/모자 포함)가 전체 키의 45~55%.** 2등신이다
  · 머리는 위아래로 살짝 눌린 **둥근 공** 모양. 헬멧이 머리를 거의 다 덮는다
  · 얼굴은 작게 아래쪽에 몰려 있다. 눈만 크고 코·입은 점 수준
  · 몸통·팔·다리는 **짧고 통통하게**. 손발은 뭉툭하게
  · 목은 거의 없다. 머리가 어깨에 바로 얹힌다

**[제일 중요] 배트가 머리에 안 가리게 그려라.**
지금 그림은 배트가 머리 위를 가로질러서, 머리를 키우면 배트가 통째로 숨는다.
답지처럼 **배트를 몸 옆(어깨 바깥쪽)으로 세워서** 머리와 안 겹치게 둔다.
배트는 짧고 굵게 — 체형에 맞춘다.

## 4단계 — 화풍

  · 선은 굵고 또렷하게. 셀 채색(그라데이션 최소)
  · 유니폼은 **흰색 바탕에 남색 포인트**. 물들이기(mvTintPixels)가
    팀 색으로 바꾸니 원본은 남색으로
  · 배팅 장갑은 흰색, 글러브는 갈색, 배트는 나무색으로 둔다
    (이 셋은 물들이기에서 제외된다 — MV_FIG_KEEP)
  · 세 장의 화풍·선 두께·채색이 **서로 같아야 한다.** 한 장만 달라도 티가 난다

## 5단계 — 끝나면

```
node art/strip.js art/받은그림.png art/bat-new.png     # 체커보드 배경이면
node art/packfig.js 85
```

`packfig.js` 가 `art/fig.b64` 와 **index.html 에 넣을 상수값**(MV_FIGS ·
MV_FIG_ANCH · MV_FIG_H)을 찍어준다. 그 값을 index.html 에 옮기면 끝이다.

[주의] 체형이 바뀌면 아래도 같이 다시 재야 한다 — packfig 가 안 잡아준다:
  · `MV_BAT_NO`  등번호 찍는 자리 (그림 픽셀 좌표)
  · `mvBatSweep` 의 `gx,gy,r`  스윙 잔상이 도는 중심과 반지름 (그립 자리)
  · `MV_FIG_H`   화면에서의 키. 2등신은 같은 키여도 훨씬 커 보인다 —
                 답지(_ref_sd_scene.png)에서 타자가 화면 높이의 몇 %인지 재서 맞춘다
```

## 받고 나서 내가 할 일 (코드 쪽)

세 장이 들어오면 아래를 다시 잡는다. 전부 `camtest.js` 가 숫자로 검사한다.

| 곳 | 왜 |
|---|---|
| `MV_FIGS` · `MV_FIG_ANCH` · `MV_FIG_H` | packfig 출력값으로 교체 |
| `MV_BAT_NO` | 등번호 자리 — 몸이 작아지면 어긋난다 |
| `mvBatSweep` 의 `gx,gy,r` | 스윙 잔상 중심이 그립이다. 그립이 옮겨간다 |
| `MV_BOXC[2]` · `mvFootRing` 반지름 | 발이 놓이는 자리와 발밑 고리 크기 |
| `MV_CAM` · `MV_CAM_Y` | 2등신은 같은 키여도 화면을 더 먹는다. 카메라를 다시 잰다 |
