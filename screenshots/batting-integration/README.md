# 승인 타격 모션: 실제 게임 통합 후보 / 배포 보류

작업 브랜치 `integrate/approved-batting`. 기준 게임은 최신 `claude/next`의 **db31b7e / v5.160.25**, 승인 모션은 **86369a5**. 처음 v5.160.22에서 작업했으나 중단 중 올라온 Claude의 v5.160.23~25를 확인하고 최신 버전 위로 재배치했다. Claude의 뉴스/선수 카드/신인상 변경은 보존했다.

**현재 상태: 실제 게임 컨트롤러와 연결하고 테스트함. 모든 코스의 새 모션 적용 완료 또는 서비스 배포 준비 완료로 판정하지 않는다. 병합·Pages 배포 미실시.**

## 실제 변경

- `visual/batting/approved/`의 다섯 포즈 모듈은 승인 커밋의 바이트/SHA256과 동일하다. `renderer.js`도 당시 렌더러 구간을 그대로 복사했다. 전역 mvSD/좌타자/야수 렌더러를 덮어쓰지 않는 별도 factory 안에 묶었다.
- `build.cjs`는 이 스냅샷과 어댑터를 단일 `index.html`에 넣는다. 게임/암호화 배포본이 검수 폴더나 외부 스크립트를 요청하지 않는다. READY 렌더러에서 타자만 그리는 경로를 노출하고, 실제 타자 유니폼·외모·등번호를 전달한다. 검수용 공·필드·자막은 게임에 넣지 않았다.
- 기존 카메라 c, 투수, 필드, 스트라이크존, 공 그리기와 조작판을 유지한다. 실제 DOM 스트라이크존/캔버스 변환을 역산해 **기존 승인 target solver**에 코스 인자로 전달한다. 별도 팔 각도나 수작업 포즈를 추가하지 않았다.
- 와인드업 시작과 실제 릴리스 시각에 READY→PLANT 시계를 연결한다. 실제 릴리스 콜백으로 예상 착지 시각을 보정한다. 수동 입력은 기존 `ACP_SWD=100ms`, AI는 기존 220ms에 맞춰 source CONTACT 1120ms가 오도록 재생 시간을 매핑한다. 원래 판정 공식과 입력 상수는 변경하지 않았다.
- 이 시간 변환은 **기존 검수 영상과 재생 타이밍이 같다는 뜻이 아니다.** 수동 입력에서는 승인된 220ms 구간을 100ms 입력 창에 재생한다. 새 접합 속도 단절을 만들지 않도록 시계에 Hermite 연결을 사용해 CONTACT 끝의 시간 배율을 EXTENSION의 1배속과 맞췄다. 준비 도중 아주 일찍 누르면 남은 스트라이드까지 빠르게 재생될 수 있다. 최종 손맛 검수가 필요하다.
- CONTACT 이후 기존 수비 화면이 380ms 만에 덮던 경우, 지원되는 새 모션은 FINISH까지 남은 시간만 더 보여준 뒤 같은 `acpField`로 넘긴다. 결과/주루/수비 엔진을 바꾸거나 새로운 주루 장면을 붙이지 않았다. 기존 홈런 대기 1150ms는 줄이지 않는다.

## 반드시 남겨둘 제한 / 배포 보류 이유

1. **새 모션은 모든 코스에서 안전하지 않다.** 승인된 중심 코스 골격의 기존 target solver로 낮고 먼 공까지 맞추려 하면 팔 길이 제약이 깨진다. 3×3 코스 표본 중 5개는 정상, 4개는 이 문제가 검출됐다(`geometry.json`). 단위 격자의 좌표는 화면 좌우가 아닌 게임의 u/w다. 실제 실행에서는 고정된 9구간 표가 아니라 해당 코스의 900~1750ms를 10ms 간격으로 검사한다.
2. 해당 코스는 팔을 늘리거나 몸통을 새로 비틀지 않고 **기존 타격 모션으로 넘긴다.** 좌타자, 역방향/다른 카메라, 액션 타석 바깥도 기존 동작을 유지한다. 따라서 “우타자 전체 코스에 최종 모션 적용 완료”라고 보고하면 안 된다. 미지원 영역을 새 모션으로 넓히려면 승인 범위를 벗어나는 리타게팅/몸통 대응 검수가 필요하다.
3. **기존 승인 모션 자체의 임팩트 직후 급감속**(source 1120→1130ms 약17.75→8.32m/s)은 이번에 재설계하지 않았다. 새 시간 변환의 접합 오류는 제거했지만 타격 전체의 자연스러움이나 물리적 타당성까지 확정한 것은 아니다. 사용자 정상속도 검수 대상이다.
4. 공 접촉 검사는 기존 **barrel proxy**를 사용한다. 지원 코스에서 proxy의 접촉 지점과 실제 UI 목표의 투영 오차는 약1.3e−13px 이하였지만, 실제 배트 메시의 정밀 충돌을 새로 구현한 것은 아니다. 25fps 실시간 녹화에는 정확한 임팩트가 프레임 사이에 빠질 수 있어 시계/투영 검사를 별도로 제출한다.
5. 모바일은 Chromium 390×844 브라우저 검증이다. 실제 휴대전화/Safari, 모든 체형·유니폼·구종, 도중 화면 회전, 지연된 백그라운드 탭을 전부 검증했다고 주장하지 않는다.
