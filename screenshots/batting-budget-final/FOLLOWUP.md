# 이번에 구현하지 않는 후속 과제

1. 공통 투구 모션: 기존 sdPitchPose의 key-pose easing과 릴리스 이후 흉곽·골반·하체의 정적인 인상을 개선할 별도 작업. 실제 투구 전신/지지발/손·공 기준점을 같은 월드 좌표·사건 시계로 검수한다. 이번 원본·키포즈는 변경하지 않았다.
2. 주루/수비: 기존 경량 표현을 바탕으로 실제 베이스 이동, 포구·송구·태그를 연결한다. 손과 공에 별도 좌표계를 만들지 않는다. 고품질 소프트웨어 깊이 renderer를 여러 선수에게 그대로 복제하는 계획은 성능 검증 없이 채택하지 않는다.
3. 오프닝/국가연주/초상화: 미술 승인이 확보된 공통3D 마스터와 LOD/정적 초상화를 별도 검증한다. 현재 곽빈3D 연구는 동결 상태를 유지한다.
4. 타격: 이번 한 차례 제한 실험의 채택 여부를 최종 보고서에 기록하고 추가 시간곡선/GPU/Worker/렌더러 재작성은 시작하지 않는다. 37573d1 후보의 기능·구도를 보존한다.

모든 항목은 별도 승인·작업 범위이며 이번 후보를 서비스에 배포하는 지시가 아니다.
